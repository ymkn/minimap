# case/ — build123d によるケース設計（CAD-as-code）

「額装された地図」モチーフのケースを build123d のコードで起こす作業場所。ワンピースバスタブ前提で、上面と側面の意匠をケース側だけで完結させる検討ライン。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `model_case.py` | 本体。`build_case()` がパラメータ付きでソリッドを返す。直接実行すると既定案を `output/` へ STEP / STL / GLTF で出す |
| `render.py` | `output/minimap_case.stl` からプレビュー PNG（上面・斜視）を描く。ヘッドレスでは `xvfb-run` 経由 |
| `variations.py` | 方向性比較用のバリエーション一括生成。`output/variants/` へ各案の STEP / STL と、上面・斜視・角アップの比較シートを出す |

## 位置づけ

- **寸法は仮置き**（外寸 128mm 角・高さ 12mm、キーフィールド 102mm = 6×17mm ピッチ）。モチーフ確認用であり、現行ケースの実寸には合わせていない。**製造未承認**（`production_ready=false` の扱いは本体ケースと同じ）。
- FreeCAD 版の額縁検討案は [`../FreeCAD/concepts/picture-frame/`](../FreeCAD/concepts/picture-frame/) にあり、現行ケースの内寸（115.5mm）を維持した実寸ベースで先行している。こちらはコードファーストでイテレーションと干渉チェックを回すための別ラインで、寸法を実寸へ寄せる時は FreeCAD 版と `../doc/case.md` を正とする。
- 生成物は Git に入れない（`output/` は除外済み）。確認用 STEP はステップビューアの棚へ公開して使う。

## 意匠メモ（2026-11-06 時点の決定）

- **額縁らしさの核は四隅の継ぎ目**（2026-11-08 本人指摘）。45°の継ぎ目があるだけで、装飾がなくても額縁に見える。ケースとして継ぎ目を作る必然性はないが、意匠として取り入れる方向で検討する。`build_case(seam=True)` で枠を横切る 0.8mm 幅の溝として表現する（現状は底面一律の切り込みで、プロファイル表面に沿わせる精緻化は今後）。
- 段差プロファイルは外側へ向かって低くなる向きで確定（外周の細いビードが最高点 Z12.0）。
- 目盛りは盛り上げず、彫り込みとしてのみ入れる（深さ 0.6mm）。帯は枠の内側だけに置き、キーフィールドへは侵入させない。
- CNC 対応を前提とする: 上面から3軸、溝・線の幅は 1.0mm 以上（φ1 エンドミル）、内角 R は 1.0 以上、目盛りとコンパススターは彫刻加工扱い。
- 左上の欠け位置（キーなしセル）の床にはコンパススターとリングを彫る。
- 親指キーの 2u 化はキーキャップの入手性のため中止済み。最下段は全て 1U のまま。

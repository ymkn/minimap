# minimap 本体ケース・奥端ウェイト

開くファイル：**`../FreeCAD/minimap.FCStd`**。`Case` Bodyが本体ケースで、`WeightMetal`・`WeightPrint` は代替ウェイト。複雑な蓋の延長や橋渡しは設けず、ウェイトは後側PCB固定二穴より奥へ配置している。

**左右110×前後14mm、ケース内座標Y42～56mm。** 手前下辺のゴム帯と奥端ウェイトのパッドで支える。傾斜5°は維持。

作業時の構造・断面図は `../archive/image/case/case-review.png`、既存検査記録は `../archive/doc/reports/current-case/`、元の作業記録は `../archive/reports/weight-plate-rear-20261103/` に保管する。これらは恒久的な説明画像や新たな製造認定ではない。

## 維持・変更した箇所

- ケース外寸120.5mm角、高さ11.6mm、壁厚・基本底厚2.5mmは維持。
- PCB四軸X=±34・Y=±36.125mm、φ2.4穴、φ5.56支柱・上端Z6.5mmは維持。各軸半径4mm内のケース形状に元CADとの差分なし。
- ウェイトは**110×14mm・R3、中心Y49mm**。後側支柱の奥側端Y38.905mmに対し、受け段凹部の手前端はY41.8mmで、約2.895mm離れている。
- 開口も奥側の**94×6mm・R2、中心Y49mm**へ移動。中央の床は残す。前へ延ばした蓋や、PCB固定穴を避けるための橋・切欠きは作らない。
- 下面受け段凹部110.4×14.4mm・R3.2、深さ1.2mm。基本の段受け残肉1.3mm。
- ウェイトの肩上面Z1.2mm、位置決め凸部93.6×5.6mm・R1.8、高さ1mm。初期隙間は片側0.2mm。
- ウェイト固定は**X=±51・Y=49mmのM3二点**。ケース穴φ3.4、頭座Z3.5mm・φ7.6mmの局所Pad。PCB固定と共締めにしない。
- 足下面は5°。ケース底面Z0からの下がりは前端約8.747mm／後端約9.971mm。肩上面からの厚さは約9.947～11.171mm、位置決め凸部は別途1mm加算。

## 接地・安定性

- 手前下辺：幅104×前後3mm、中心Y−58mmのゴム帯。CADは厚さ約0.469～0.731mmのくさび状参考包絡。
- 奥端：10×4×0.6mmのパッド二枚、中心X=±47・Y=53mm。
- 両者の下面が同じ水平な机面Z0に接する。硬いウェイト下面はZ0.6mm、ケース最低点は机から約0.427mm離れる。
- 接地部で囲む支持範囲は**左右104×前後約114.877mm**。前案の約104×87mmから奥行方向へ拡大した。全域が接地するのではなく、手前帯と奥の二枚で囲む領域を指す。

支持位置を最上段側へ近づけたが、実物の重心・押下荷重・ゴムの圧縮・接着・机の平面性による安定性は未認定。一定厚のゴムを使う場合、手前帯の傾斜分を圧縮・厚さ・貼付位置で現物調整する必要がある。

参考密度での金属版単体概算は**アルミ約45g、鋼約131g、真鍮約141g**。材質は未確定であり、以前の大きなプレートと同じ重量にはならない。3DP版も同重量とは扱わない。

## 代替Bodyと金具

| オブジェクト | 用途 |
|---|---|
| `Case` | 奥側の細い開口を持つ共通ケース |
| `WeightMetal` | 金属タップ版。初期表示 |
| `WeightPrint` | 3DP貫通穴・ナット版。初期非表示 |
| `MetalFasteners` / `PrintFasteners` | 各版の公称金具参考形状 |
| `ContactPads` / `FrontContactStrip` | ゴム参考形状 |
| `WeightParams` | 足・開口・締結・接地寸法 |

両ウェイトは代替品で、同時に使用しない。3DP版を見るときは `WeightMetal` と `MetalFasteners` を隠し、`WeightPrint` と `PrintFasteners` を表示する。Bodyの表示は `DisplayModeBody=Tip`。金具・ゴム・PCB等は固定の参考包絡であり、パラメーター変更時は関連参考形状と検査も再生成する。

- PCB四本：極低頭M2×8、頭φ4×高さ0.5mm、公称掛かり1.5mm。
- 金属版二本：低頭M3×6、頭φ5.5×高さ2mm、M3×0.5タップ、公称掛かり3.7mm。
- 3DP版二本：低頭M3×8、頭φ5.5×高さ2mm、貫通φ3.4mm、ナット対辺5.5×高さ2.4mm参考。六角ポケット対辺5.8mm、水平ナット座上の肉厚3mm。

実在製品の選定・有効掛かり・強度は未認定。金属版のタップは呼び径φ3・深さ4.5mmの簡略包絡で、ねじ山はない。下穴φ2.5mmは参考値。**STEPのφ3包絡を下穴加工寸法として使わない。** 実際のドリル先端・タップ食付き・不完全ねじ部・底肉は加工工程で確定する。

組立は、3DP版では下面へナットを入れ、ウェイトを嵌め、**PCB搭載前にケース内側からM3二本を締結**する。その後PCBを載せ、ケース底側からM2四本を締める。四軸のねじ頭・工具経路をウェイトは塞がない。PCBに工具用の穴は追加していない。

## 出力と検査

現行出力は `../FreeCAD/STEP/` 内の3点のみ。

- `minimap_case.step`：本体ケース（`Case`）。
- `minimap_weight_metal.step`：金属版ウェイト（`WeightMetal`）。タップ加工指示ではない。
- `minimap_weight_print.step`：3DP版ウェイト（`WeightPrint`）。金属版の代替案で、ケースと同じ設計座標。印刷姿勢・サポートはスライサーで確認する。

3点とも保存済みCADの形状との体積・外接寸法・双方向の形状差を照合済みで、有効な単一ソリッド。CADを編集した場合、対応STEPも更新する。CAD本体の変更・再保存やSTEPの再生成は今回行っていない。

前側ゴム帯は実製品形状ではなく理想化参考包絡のため、参考STEPとSTL一式は `../archive/freecad-exports-20261104/` に保管する。CAD内の `FrontContactStrip` は維持する。

既存の設計検査では29スケッチ完全拘束・Block拘束0、取得済みモデルとの静的干渉0、ねじ取付け経路・水平接地を確認している。これらは過去の記録であり、今回新たに再計算・認定したものではない。

**製造未承認。** 実物での転倒安定性、ゴム、締結・接合強度、樹脂クリープ、公差、実金具、実USBプラグ／ケーブル、全実装部品は未確認。USB上側の既存肉厚約0.915mm、U3モデル欠落、スイッチ／プレート着座高さ未認定も継続。検討用STEPを、そのまま本番製造・金属加工発注へ使用しない。`production_ready=false`。
